Frequently Asked Questions

1. How to play the game (Browser Version)?
To play the game, you need a modern web browser that supports WebGL2.
Steps:
  1. Go to the website: Catch The Coins on itch.io
  2. Click the red "Run game" button.
  3. Enjoy!
2. How to play the game (Windows PC Version)?
To play the game, you need a device running Windows OS (Windows 8.1 or higher!).
Steps:
  1. Go to the website: Catch The Coins on itch.io
  2. Scroll down to the "Download" section.
  3. Click the red "Download" button next to "Catch The Coins Windows.zip".
  4. Unzip the downloaded .zip file.
  5. Run the .exe file.
  6. Enjoy!
3. What should I do if a Temp folder error appears when launching the .exe file?
Steps:
  1. Run the .exe file as administrator (Right-click -> Run as administrator).
4. What should I do if a .pck file error appears when launching the .exe file?
This happens if the .pck file was corrupted or deleted.

Steps:
  1. Reinstall the game (see Section 2 of this FAQ).
Don't worry, your progress will be saved!
5. How do I control my character?
You can control your character using:
  • Keyboard: Use A / D keys or Arrow keys to move left and right.
  • Touch Controls: On mobile devices or tablets, enable the "Touch" option in the settings menu to show screen control buttons.
6. How to unlock new levels?
To unlock the next level, you need to survive until the timer reaches 0 on the current level without dying!
7. Will my progress sync between Browser and Windows versions?
No, the Browser and Windows versions save progress independently. The Web version stores save data in your browser's local cache, while the PC version saves it locally on your computer.
8. How do I equip unlocked skins?
Go to the Customization menu, click on any unlocked skin or player color, and it will automatically equip to your character!
